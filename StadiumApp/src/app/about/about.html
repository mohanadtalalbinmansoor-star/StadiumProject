About Stadium Reservation System

A web-based platform designed to simplify sports stadium management, hourly slot scheduling, and online customer bookings with automatic conflict prevention.

Instant Booking

Reserve stadiums by the hour with automatic price calculation and real-time availability checks.

Custom Policies

Each stadium defines its own opening hours, slot duration, and cancellation rules.

Modern Architecture

Developed using ASP.NET Core Web API, Entity Framework Core, and Angular SPA.
